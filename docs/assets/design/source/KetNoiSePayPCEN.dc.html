SePay handover · server part

1
Connect to the serverSSH with the installer's key only. There is no web page for this.
$ ssh stayguard@[MÁY-CHỦ]
2
Create the guesthouse from a file (task P2)The file holds buildings, rooms, rates, extras, receiving account and staff. Keep it out of git; delete it from the server after import.
$ stayguard tenant import --file nnabc.json
✓ Tạo nhà nghỉ NNABC · 2 tòa · 35 phòng
✓ PIN dùng một lần cho 5 nhân viên đã in ra (hết hạn sau 24 giờ)
3
Get the guesthouse's webhook addressRead it to the owner to paste into SePay.
$ stayguard sepay webhook --tenant NNABC
https://[TÊN-MIỀN]/v1/webhooks/bank/hk_7Q…
4
Enter the secretThe command prompts and hides input. Never pass the secret as an argument or environment variable, so it never lands in shell history.
$ stayguard sepay set-secret --tenant NNABC
Khóa bí mật SePay: ••••••••••••
✓ Đã lưu (mã hóa) · ghi nhật ký: Người cài đặt cập nhật kết nối SePay
5
Test and confirmSimulate an incoming transfer in SePay Test mode, then one real ₫2,000 transfer in Live mode.
$ stayguard sepay status --tenant NNABC
Đã kết nối · webhook nhận lần cuối 14:01 · chữ ký hợp lệ
Safety rules
The secret is write-only; no command prints it back.
Every change appears in the owner's activity log.
If the secret leaks: create a new one in SePay and repeat step 4.
Owner changes bank account: redo the owner's part.

These command names are proposals; Claude Code builds them in tasks P2 and P3 of docs/14.
