One interface that rearranges itself by screen size

The phone, tablet and desktop boards on this canvas are the same page at three widths, not three apps. Each page has one route and one set of components; only the layout changes at the breakpoints below.

Same at every size
Data, money rules, permissions, wording and the order of steps. Touch targets are always at least 44px.
For the code
Tailwind: default is phone, md: (640px) is tablet, lg: (1024px) is desktop. No separate routes or components per device.
Checks
Every page is checked at 390, 834 and 1280px in both languages; no sideways scroll, no text overflowing buttons.
