# Release Notes

Protocol: docs/11 §8. Newest first. Each feature entry is written in the feature's PR under Unreleased and moved under a version heading at release.

Entry template:

```
### <Feature title> (SG-xxx, slice Sx)
What's new: at most three sentences in user language.
Who it is for: role.
How to try it: screens or steps.
Changes and migration: behaviour changes, or "none".
Known limits: what it does not do yet.
API: operationIds touched. Flag: FF_... (removed in vX.Y.Z).
Links: docs and ADRs.
```
