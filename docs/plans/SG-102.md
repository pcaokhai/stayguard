Status: merged (PR #12, 828feca); ADR-015 accepted

Migration number reserved: 0004.

## Understanding
docs/06 SG-102 asks for demo sessions (AC1), opaque 256-bit tokens stored as SHA-256 hashes with a TTL (AC2), `/v1/me` and locale (AC3), middleware that turns a token into a tenant-scoped caller (AC4) and an `Authorizer` covering docs/04 §2.3 (AC5). ADR-010 fixes the model (role-picker sessions, same `Authorizer` in production); ADR-005 and SG-003 Ruling 11 mean the session row cannot be read before the tenant is known, which is the open decision, written as ADR-015 (Proposed, recommends a hash-scoped SELECT-only policy). `building_permissions` is SG-501's table, so building access here is derived (owner EDIT everywhere, everyone else NONE) behind a port SG-501 replaces. Trial cloning, rate limits and cleanup are SG-601; this story creates an empty trial tenant when no `tenantId` is sent (Ruling 2).

## Interfaces (in words)
- Lookup: `Resolve(ctx, tokenHash)` opens a short transaction, sets the hash setting locally, selects tenant, user and expiry of that one row, and returns not-found when no row. Nothing else uses the setting. All later work goes through `UnitOfWork.Do(tenant)`.
- `Authenticate(token)`: hash, resolve, compare expiry with the injected clock, load user and role inside the tenant transaction, return a Caller (tenant, user, role, locale). The server clock is the only time source (rule 3).
- `CreateDemo(role, locale, optional tenantId)`: with a tenantId, join it only if it is an unexpired trial (generic not-found otherwise); without, create a trial tenant with a server-made id. Find the user for the role or create it (name from the role, retry once on 23505), insert a session with a fresh token hash, return the raw token once.
- `Me` lists the tenant's buildings with level from `domain/access` (owner EDIT, others NONE until SG-501).
- `Authorizer.Check(operationId, role, level)` returns nil, ErrRoleForbidden or ErrBuildingForbidden; handlers of later stories call it with the building of the touched record.

## Rulings (decisions needing the tech lead)
1. ADR-015 (Proposed): session lookup by hash through a SELECT-only policy that applies only while no tenant is set. Alternatives and the fallback are in the ADR. Overturn before merge; later migrations depend on it.
2. Tenant for a session without `tenantId`: an empty trial tenant, not a cloned fixture (SG-601 owns cloning, rate limits and cleanup). Rate limiting (429) and trial cleanup are therefore not in this story. DEPLOY GATE: `DEMO_MODE` must stay off in any publicly reachable deploy until SG-601 is merged, because an anonymous client could otherwise create unbounded tenants, users and sessions.
3. DEMO_DISABLED: the generated route stays registered; the handler returns 404 `DEMO_DISABLED` before any I/O when DEMO_MODE is off. `api/CLAUDE.md` said "not registered"; it is updated. Confirm.
4. Building access derived (owner EDIT, others NONE) until SG-501 adds the table; `getMe` therefore shows NONE for staff until then.
5. New config keys DEMO_MODE, SESSION_TTL_HOURS, TRIAL_TTL_HOURS. No new dependencies; ULID, token and hashing use the standard library. No tool added.
6. Size: estimated 900 to 1100 changed lines excluding generated code, over the 400 limit. Proposed split: PR A = ADR-015, migration, lookup adapter, Authorizer, config (data path and AC5); PR B = use cases, middleware, handlers (AC1 to AC4). Or one PR with a recorded exception as in SG-002 and SG-003.
7. Final security review (opus): no Critical, ADR-015 accepted as is (fallback SECURITY DEFINER under a NOLOGIN role gives the same capability at higher cost). Made during execution: more than one `Authorization` header is rejected; bare `/v1` is protected; `tenantId` is only a lookup key (shape-checked, 64 bytes of `[A-Za-z0-9_]`) and works as a bearer key to open sessions in that trial (80 random bits stop enumeration; a joiner overwrites the shared role user's locale); session TTLs capped at 24*365 hours; trial sessions may outlive the trial by up to the session TTL.
8.
