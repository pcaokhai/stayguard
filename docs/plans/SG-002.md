## Understanding
SG-002 (docs/06) turns `contracts/openapi.yaml` (3.1.0, 28 operations) into a gated pipeline: `make contracts` runs Spectral, oasdiff against `main`, JSON Schema compilation and `generate_vectors.py --check`, and CI fails on any error (docs/04 §135 flow, docs/08 §2 contract row, docs/02 §9 tool list, ADR-003). `make gen` creates Go strict server stubs (oapi-codegen), a typed TypeScript client (openapi-typescript + openapi-fetch) and MSW handlers, so API and WEB build in parallel (CLAUDE.md §5) and `web/` runs with `NEXT_PUBLIC_MOCK=1` and no API. The contract uses `oneOf` with `type: 'null'` and `const`, so the R-14 spike (docs/09) must record which 3.1 features each generator handles; if any used feature fails, the fix is a contract PR downgrading to 3.0.3 plus an ADR-003 update, never a change inside this branch (CLAUDE.md §9). Because this story is blocked from editing `contracts/` in a feature branch, any downgrade is a separate, earlier contracts PR. SG-001 left the `gen` and `contracts` Makefile stubs and best-guess Read denies in `.claude/settings.json` (docs/plans/SG-001 Ruling 5), which this story finalises. No design decision is open beyond the spike, so no brainstorming; outcome of the spike goes into ADR-003.

## Interfaces in words
- `make contracts`: no input; exit 0 only if all four steps pass; output names the step that failed. Base for oasdiff is `origin/main:contracts/openapi.yaml` locally and in CI; if the base file does not exist yet (first run), the step passes with a notice.
- `make gen`: no input; writes only the three generated directories; running it twice yields no diff; overwrites generated files, and drift is caught by the CI diff step.
- Generated Go: one strict handler interface with one method per operationId and typed request and response objects; the router registers it behind the existing chi router. Missing method means a compile error.
- Generated TS: path-typed definitions consumed by openapi-fetch; mock handlers return the examples in the spec or fixtures from `contracts/fixtures/`, status codes and `problem+json` errors included.
- Mock switch: `NEXT_PUBLIC_MOCK=1` starts the MSW worker at app start; unset means real `/v1` calls.

## Risks and rollback
- MSW 3.x is a new major; generators may lag it. Mitigation: spike checks compatibility; fall back to the generator's supported MSW range and pin it, or to handlers generated by a small script.
- Spectral may report existing issues in the spec; fixing them in this branch would breach the contracts rule, so they become a contracts PR or a documented rule override.
- oasdiff base on first CI run or shallow clones: `fetch-depth: 0` and a missing-base notice.
- ESLint stays at 9.39.5 (deprecated warning) until eslint-config-next supports ESLint 10; this story does not upgrade it.
- Rollback: one squash-merged PR; revert it. The Makefile stubs return with the revert.
