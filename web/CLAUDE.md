## Structure

`src/app/[locale]/…` pages (static params `vi`, `en`; ids in the query string, components using `useSearchParams` inside `Suspense`) · `src/features/<area>/` hooks and views · `src/components/ui` (shadcn) · `src/components/shell` (top bar, icon rail, owner sidebar, front-desk bar) · `src/components/motion` (primitives from docs/16 §4) · `src/lib` (api client, t(), money, time, motion tokens) · `messages/vi.json`, `messages/en.json` · `e2e/` (Playwright: layout, smoke).

## Rules

- Data only through the generated client in `src/lib/api.ts` and TanStack Query hooks per feature. No raw `fetch` to `/v1`.
- Session: production sign-in (`signIn`) stores the token in `sessionStorage`; demo role picker only when demo mode is on; 401 goes to sign-in; 403 shows KhongCoQuyen.
- Writes send an `Idempotency-Key` (one UUID per user action, reused on retry); the button shows a spinner and is disabled while pending.
- Show money exactly as the API returns it, formatted `Intl.NumberFormat('vi-VN')` + `đ` (en: `₫` prefix). Never compute prices in the browser. Never animate amounts on pay, bill, receipt or checkout screens.
- All text through `t('key')`; no hard-coded Vietnamese or English in components. Every UI task adds keys to `messages/vi.json` and `messages/en.json` together; English text comes from `docs/assets/design/source/<Board>EN.dc.html`.
- Responsive with Tailwind breakpoints: default phone, `md:` tablet (640 px), `lg:` desktop (1024 px). Use the shadcn responsive-dialog pattern (Drawer on phone, Dialog or Sheet from `md:`). Tables become cards on phone; wide tables scroll inside their card with a sticky first column.
- Touch targets ≥ 44 px; labels stay on one line; every status has text, not only colour.
- Motion: tokens and primitives from docs/16 §4; `MotionConfig reducedMotion="user"`; only transform and opacity.
- Mock mode (`NEXT_PUBLIC_MOCK=1`) must keep working: after `npm run gen`, add realistic data for your screens in `src/mocks/setup/demo-handlers.ts`.
- Navigation shows only pages that exist.

## Done for a UI task

`npm run build`, `npm run lint`, `npx playwright test e2e/layout.spec.ts` pass; every board in the task checked with `scripts/ui-shots.sh` at its width and the other two widths, on `/vi` against `<Board>.png` and on `/en` against `<Board>EN.png`, and listed as match or differences in your report; the happy path works on mocks, and against `make up` once the API task is merged.
